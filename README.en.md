## About the Project

This project was developed as the certification 2 project for track 3 of DEVstart. It's a complete task management application (to-do list) with an intuitive interface and full CRUD functionalities.

## Features

- Add new tasks
- View task list
- Edit existing tasks
- Delete tasks
- Mark tasks as completed
- Data persistence with localStorage
- Interactive notifications with toasts
- Responsive and modern interface

## Technologies Used

- **React 19** - JavaScript library for building user interfaces
- **Vite** - Modern and fast build tool
- **React Router DOM** - Route management
- **Context API** - Global state management
- **React Hot Toast** - Elegant notifications
- **React Icons** - Icon library
- **LocalStorage** - Data persistence

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/flaviare1s/aplicacao-de-tarefas.git
```

2. Install dependencies:

```bash
npm install
```

3. Run the project in development mode:

```bash
npm run dev
```

4. Access in your browser:

```
http://localhost:5173
```

## Available Scripts

- `npm run dev` - Starts the development server
- `npm run build` - Creates the production build
- `npm run preview` - Previews the production build
- `npm run lint` - Runs the linter

## Implemented Requirements

- Environment setup with Vite
- React Router for page navigation
- Context API for global state management
- Hooks (useState, useEffect, useContext)
- Full CRUD operations for tasks
- Persistence with localStorage
- Componentization
- Modern and responsive interface
- Visual feedback with toasts
